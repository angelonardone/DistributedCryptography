Build the application yourself if you want to audit the code or check the build. You need the
[.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0) and git.

:::tip
If you only want to run the code from the repository without installing the .NET SDK, use
[Docker](/install/docker/): it builds the same source inside a container.
:::

These are the same commands that build the [ready-made downloads](/install/): the installers are built by
GitHub from this repository, with the workflow
[release.yml](https://github.com/angelonardone/DistributedCryptography/blob/main/.github/workflows/release.yml).

<Steps>

1. **Get the code:**

   ```bash
   git clone https://github.com/angelonardone/DistributedCryptography
   cd DistributedCryptography
   ```

2. **Build.** The first command compiles the application and the second one adds the program that starts it:

   <Tabs syncKey="os">
   <TabItem label="Windows">
   ```powershell
   dotnet publish src\build\Deployment.slnx -c Release -r win-x64 --self-contained true
   dotnet publish src\build\GxWebStartup\GxWebStartup.csproj -c Release -r win-x64 --self-contained true -o web\bin
   ```
   </TabItem>
   <TabItem label="Mac">
   ```bash
   dotnet publish src/build/Deployment.slnx -c Release -r osx-arm64 --self-contained true
   dotnet publish src/build/GxWebStartup/GxWebStartup.csproj -c Release -r osx-arm64 --self-contained true -o web/bin
   ```

   On a Mac with an Intel processor use `-r osx-x64` instead of `-r osx-arm64`.
   </TabItem>
   <TabItem label="Linux">
   ```bash
   cp src/Directory.build.props src/Directory.Build.props
   dotnet publish src/build/Deployment.slnx -c Release -r linux-x64 --self-contained true
   dotnet publish src/build/GxWebStartup/GxWebStartup.csproj -c Release -r linux-x64 --self-contained true -o web/bin
   ```

   On ARM use `-r linux-arm64` instead of `-r linux-x64`. The first line is needed because Linux tells
   upper-case and lower-case letters apart in file names.

   QR codes need the library `libgdiplus` and one setting: see [QR codes on Linux](/install/linux/#qr-codes).
   </TabItem>
   </Tabs>

3. **Start** the program from the `web` folder:

   <Tabs syncKey="os">
   <TabItem label="Windows">
   ```powershell
   cd web
   bin\GxWebStartup.exe
   ```
   </TabItem>
   <TabItem label="Mac">
   ```bash
   cd web
   ./bin/GxWebStartup
   ```
   </TabItem>
   <TabItem label="Linux">
   ```bash
   cd web
   ./bin/GxWebStartup
   ```
   </TabItem>
   </Tabs>

4. In **another terminal**, open the application in your browser:

   <Tabs syncKey="os">
   <TabItem label="Windows">
   ```powershell
   start http://localhost:5000/wallet.wallets.aspx
   ```
   </TabItem>
   <TabItem label="Mac">
   ```bash
   open http://localhost:5000/wallet.wallets.aspx
   ```
   </TabItem>
   <TabItem label="Linux">
   ```bash
   xdg-open localhost:5000/wallet.wallets.aspx
   ```
   </TabItem>
   </Tabs>

</Steps>
