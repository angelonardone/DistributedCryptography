Build the application yourself if you want to audit the code or check the build. You need the
[.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0) and git.

:::tip
If you only want to run the code from the repository without installing the .NET SDK, use
[Docker](/install/docker/): it builds the same source inside a container.
:::

<YouTube id="9XtY_TF5FZI" title="Building the application from source" />

<Steps>

1. **Get the code:**

   ```bash
   git clone https://github.com/angelonardone/DistributedCryptography
   cd DistributedCryptography
   ```

2. **Clean** the project:

   <Tabs syncKey="os">
   <TabItem label="Windows">
   ```powershell
   dotnet clean src\build\Deployment.sln
   ```
   </TabItem>
   <TabItem label="Mac / Linux">
   ```bash
   dotnet clean src/build/Deployment.sln
   ```
   </TabItem>
   </Tabs>

3. **Build:**

   <Tabs syncKey="os">
   <TabItem label="Windows">
   ```powershell
   dotnet publish -r win-x64 --self-contained true src\build\Deployment.sln --output .\web\bin /p:GxExternalReference=\"NBitcoin.dll;NBitcoin.Secp256k1.dll;QRCoder.dll;Google.Authenticator.dll;SecretSharingDotNetCore.dll;Konscious.Security.Cryptography.Argon2.dll;Konscious.Security.Cryptography.Blake2.dll;SharpCompress.dll\"
   ```
   </TabItem>
   <TabItem label="Mac / Linux">
   ```bash
   dotnet publish -r osx-x64 --self-contained true src/build/Deployment.sln --output web/bin /p:GxExternalReference=NBitcoin.dll%3bNBitcoin.Secp256k1.dll%3bQRCoder.dll%3bGoogle.Authenticator.dll%3bSecretSharingDotNetCore.dll%3bKonscious.Security.Cryptography.Argon2.dll%3bKonscious.Security.Cryptography.Blake2.dll%3bSharpCompress.dll
   ```

   On Linux use `-r linux-x64` instead of `-r osx-x64`.
   </TabItem>
   </Tabs>

4. **Start** the program from the `web` folder:

   ```bash
   cd web
   dotnet bin/GxNetCoreStartup.dll 5000
   ```

5. In **another terminal**, open the application in your browser:

   <Tabs syncKey="os">
   <TabItem label="Windows">
   ```powershell
   start http://localhost:5000/wallet.wallets.aspx
   ```
   </TabItem>
   <TabItem label="Mac / Linux">
   ```bash
   # Mac
   open http://localhost:5000/wallet.wallets.aspx
   # Linux
   xdg-open localhost:5000/wallet.wallets.aspx
   ```
   </TabItem>
   </Tabs>

</Steps>
