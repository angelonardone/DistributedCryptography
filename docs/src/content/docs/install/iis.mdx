By default the application runs on Kestrel, the web server that comes with .NET. On a Windows server you can put
Internet Information Services (IIS) in front of it.

<Steps>

1. Install the **ASP.NET Core Runtime 10 Hosting Bundle** from the
   [.NET 10 download page](https://dotnet.microsoft.com/download/dotnet/10.0). IIS must be restarted afterwards.

2. Download and unzip the zip file of the application (see
   [Install on Windows, without the installer](/install/windows/#without-the-installer)). IIS needs
   permission to read the files; the simplest way is to put the application under `C:\inetpub\wwwroot`.

3. If they do not exist, create these folders inside the application folder and give **IIS_IUSRS** full access
   to them:

   - `PrivateTempStorage`
   - `PublicTempStorage`
   - `Wallets`

4. In IIS Manager, create a new web site that points to the application folder.

5. If the site can be reached from outside your network, install a certificate so that all the traffic is
   encrypted (HTTPS).

6. Open `https://<your web site>/wallet.wallets.aspx` in the browser.

</Steps>

<YouTube id="wJBd0skHHag" title="Installing on Internet Information Services" />

:::caution[The first online login must be done on the server itself]
For security, the first time a wallet uses the online features you have to log in to our servers **from a
browser on the server**, not through the public web site.
:::

<YouTube id="nswh6xExF-k" title="Creating your first wallet on IIS" />

:::danger[Think before exposing a wallet to the internet]
Anyone who can open the site can see the list of wallets and try passwords. Use HTTPS, restrict who can reach
the site, and remember that the [HSM](/offline/hsm/) REST service has no authentication.
:::
